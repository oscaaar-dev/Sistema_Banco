# Base documental de Nori

Documentos que Nori puede usar para responder (recuperación local, sin servicios externos). Ver `docs/nori.md`.

Solo se indexan los archivos `*.md` de esta carpeta (excepto este README) que tengan `status: verificado` en su cabecera.
Cada dato debe poder comprobarse en las páginas públicas de Norte o en el código (campo `sources`).

**No** escribas aquí contraseñas, claves, correos, datos de clientes, bases de datos, documentación interna de
infraestructura ni funciones de administración. Nori rechaza al indexar los archivos que contengan secretos.
